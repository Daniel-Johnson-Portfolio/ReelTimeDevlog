At 5 AM the clock starts: 93 hours to build a game in Unreal Engine 5.9 for the Epic AI MegaJam, with a crew of Claude Code sessions. Today was about making sure they can work without tripping over each other.

## The setup

- **The Director** is the only session I talk to. It turns what I want into tasks and tells me when something's ready to look at.
- **The engine session** owns the open editor. Everyone else hands it kits: scripts that build their assets.
- **UI, gameplay and NPC AI** each own their own folders and never write in anyone else's.
- **A floater** picks up overflow from whoever is busiest.

Every session has an inbox folder. When one finishes a task, the Director hears about it automatically.

> The rule that matters most: don't suffer silently. If a tool fights you, write it down, and the toolsmith fixes it.
