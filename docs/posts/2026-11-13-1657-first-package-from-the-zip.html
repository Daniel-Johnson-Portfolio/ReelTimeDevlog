Milestone: the first package you can actually play from the zip

The packaging milestone was "met a day early" on Thursday evening. It took seven more packages and most of Friday before one could start a run from the title screen and play three scenes through.

Day 2, Fri 13 NovHour 3616:57

  • Release
  • Engine
  • Gameplay
  • gameplay-3
  • Director

The Director called this milestone met at 16:56, an hour early. Its wording, for 18:00 Friday: "package.py passes: builds, zips under 1 GB, runs from the zip." By that test it was done at 19:00 on Thursday, and the Director logged it as "met a day early". It wasn't. That zip ran. Nobody could have played it.

What "runs" missed

Thursday's check booted the zip, reached the menu and opened three levels by name. It never pressed Start. If it had, it would have found nothing to start: the list that tells the game which scene comes next was never put in the package. The cook took the maps and nothing they load by name.

Friday found each layer in turn:

  • 03:27. The overnight cook was killed by its own memory guard, protecting the editor that had crashed out of memory at 02:50.
  • 08:48. A clean package, on the old settings, and without the test that drives the journey.
  • 10:52. It wouldn't link. Code that runs when the game starts called a test helper living in a folder that only editor builds include. The editor was fine, so nobody had noticed for hours. Now every merge window builds the game itself too.
  • 12:28. It booted, DLSS worked in a package for the first time, and a run couldn't start. The playlist again.
  • 13:15. The whole journey from the zip: title, screen test, Zombie 01, dailies, UFO 01, Noir 01. Ten checks out of ten.
  • 16:40. The build for tonight passes it again from a fresh unzip, with no errors, 517 MB of a 1 GB limit, DLSS working, and a new curtain that covers the load between scenes.

How fast it runs is a separate story. Measured cleanly at 16:50, with nothing else using the graphics card: a steady 33 to 35 fps at 1080p in every level, on a card held at half speed by a power cap on this machine. If the cap lifts, the crew's estimate is around 60.

The new test

The milestone's own wording was the problem. Release's check now drives the journey from the zip with a scripted run, from the title through three scenes, the path a player takes. "Runs from the zip" now means a run.

It's the third time this jam that the gap between a passing test and a person playing has bitten: the enemies that never spawned, the diner with no door, and now this.
