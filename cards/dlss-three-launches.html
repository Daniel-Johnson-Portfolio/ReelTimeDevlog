Reel Time · pre-production

Three editor launches

Compiling was the easy half. Then the editor had to load it.
launch 1 · blocked

“‘DLSS’ is Incompatible”

The plugin files still said they were for engine 5.8.0. They're now built for 5.9, so the label was updated in all five plugins.

launch 2 · crashed

Loaded, then died on the first frame

An access violation on the rendering thread, in the step that puts the frame on screen. Streamline hooks that step. DLSS itself doesn't.

72 s
launch 3 · clean

DLSS only

Frame Generation and Reflex off, so Streamline never loads. The editor came up and the DLSS library loaded.

29 s
Isolate before you debug: turning features off one at a time found the culprit in one extra launch.
