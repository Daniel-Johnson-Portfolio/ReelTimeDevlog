The jam rules ask for anything made before the start to be declared, including prompts and scripts. Everything here is workflow tooling built during setup. None of it is game content: no design, code, levels, art or audio for the game existed before Thursday 12 November.

(The devlog session keeps this page in line with Release/DECLARATION.md.)

- **The crew setup:** shared rules, one instruction file per session, a task and inbox system, a status board, day and night mode, and a few Claude Code hooks, subagents and skills.
- **A kit template:** an empty script skeleton for importing and building Unreal assets.
- **Release tools:** a packaging and smoke-test script and a script that cuts the gameplay video.
- **This site's generator** and its templates.
